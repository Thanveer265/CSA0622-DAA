# 📖 About

This repository contains the implementation of various **Design and Analysis of Algorithms (DAA)** laboratory programs written in **C**.

The programs demonstrate classical algorithms, sorting techniques, searching algorithms, divide-and-conquer methods, brute-force techniques, and computational geometry concepts while analyzing their **time and space complexities**.

---

# 🎯 Course Objectives

- Understand algorithm design techniques.
- Analyze time and space complexity.
- Implement searching and sorting algorithms.
- Learn brute force algorithms.
- Apply divide and conquer techniques.
- Solve computational geometry problems.
- Compare algorithm efficiency.
